# CS16 Project Website

Редактируемый статический шаблон игрового сайта в стиле классических GameCMS-сайтов.

## Запуск
Открой `index.html` через локальный сервер. Для GitHub Pages просто загрузи содержимое репозитория и включи Pages.

## Что редактировать
- `data/servers.json` — сервера.
- `data/users.json` — пользователи.
- `css/style.css` — внешний вид.
- `js/main.js` — логика.
- HTML-файлы — страницы.

Авторизация, регистрация, форум и остальные динамические функции сейчас являются демонстрационным фронтендом. Для реального аккаунта/БД нужен backend.
