# Главная страница игрового портала

Сайт сделан как статическая GitHub Pages-версия по предоставленному скриншоту.

## Что уже работает

- адаптивная главная страница;
- тёмная стилистика и структура как на скриншоте;
- сервер `46.174.49.52:27013`;
- автоматический запрос названия, карты, игроков и слотов через GameDig API;
- обновление статуса каждые 30 секунд;
- кнопка подключения копирует `connect 46.174.49.52:27013`;
- навигационные якоря;
- демо-регистрация/авторизация через localStorage браузера.

## Важно про настоящий сайт

GitHub Pages сам по себе является статическим хостингом. Браузер не умеет напрямую отправлять UDP A2S-запросы к CS 1.6. Поэтому для живой информации используется HTTP API-прокси GameDig. Сам GameDig прямо указывает, что его нельзя выполнять непосредственно в браузере, а запрос нужно делать на серверной стороне/API.

Для настоящих аккаунтов, форума, банлиста, магазина, заявок, сообщений и статистики потребуется backend + база данных. LocalStorage в этой стартовой версии — только рабочая демонстрация интерфейса.

## GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень:
   - `index.html`
   - `style.css`
   - `app.js`
   - папку `assets`
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`.
6. Нажмите Save.
7. GitHub опубликует сайт на `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Для user-site можно назвать репозиторий `ВАШ-ЛОГИН.github.io`, тогда адрес будет `https://ВАШ-ЛОГИН.github.io/`.

Для собственного домена его можно добавить в Settings → Pages → Custom domain.
